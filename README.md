# 🎯 Jeu de Devinette de Nombre  

Ce mini projet je l'ai réaliser en premier année,
Un jeu web simple et interactif où l'utilisateur doit deviner un nombre secret choisi aléatoirement par le programme.

## 📝 Description

Le jeu consiste à deviner un nombre secret caché entre **1 et 100** généré aléatoirement.
